# Model Autopsy

> Find Out Why AI Fails.

A research-oriented ML robustness testing platform for studying model behavior under controlled distribution shifts and input perturbations.

## Project Structure

- **`frontend/`**: Web user interface for model evaluation, stress test configuration, and interactive analysis dashboards.
- **`backend/`**: Application backend, REST API, orchestration, and persistence services.
- **`ml_engine/`**: Core research engine implementing stress testing, perturbations, distribution shifts, metrics, and failure analysis.
- **`docs/`**: Architecture documentation, research notes, API references, and architectural decision records.
- **`tests/`**: Global end-to-end, integration, and cross-cutting test suites.
- **`scripts/`**: Automation scripts for setup, data ingestion, experiment execution, and utilities.
- **`configs/`**: Configuration templates and definitions for models, stress tests, and environments.
- **`examples/`**: Reproducible examples and walkthrough experiments.
